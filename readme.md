This repository contains the code and methodology for classifying music genres from noisy audio mashups. The project addresses the distribution gap between clean training data and noisy, mixed test data in the context of audio classification.

## Project Overview

The primary challenge of this project was the extreme "distribution gap" - the provided training data consisted of 1,000 clean audio stems (drums, vocals, bass, other) perfectly balanced across 10 genres. However, the test dataset consisted of noisy, layered mashups containing overlapping stems and background noise (ESC-50).

To solve this, a custom data generation pipeline was created to synthesize 10,000 training samples that mimic the noisy test environment. Various machine learning and deep learning models were then evaluated, culminating in an ensemble approach utilizing transfer learning.

## Dataset Details

*   **Genres (10):** Blues, Classical, Country, Disco, Hiphop, Jazz, Metal, Pop, Reggae, Rock.
*   **Original Data:** 1,000 songs (100 per genre), separated into stems. Sampling rate: 16,000 Hz. Length: ~30 seconds.
*   **Generated Training Data:** 10,000 synthetic mashups generated by mixing 4 different songs from the same genre and injecting ESC-50 noise at random scaling levels (0.05 to 0.5).
*   **Test Data:** 3,020 noisy mashup recordings.

## Methodology Pipeline

1.  **Exploratory Data Analysis (EDA):** Baseline checking of audio properties, extraction of Mel-Spectrograms, and Root Mean Square (RMS) energy verification to remove dead stems.
2.  **Data Generation:** Synthesis of 10,000 noisy samples to overcome the distribution gap. A `StratifiedGroupKFold` split (5 folds) was used, grouping by the original song ID to prevent data leakage during validation.
3.  **Baseline Models:**
    *   Random Forest and Gradient Boosting utilizing 1D MFCC (Mel-Frequency Cepstral Coefficients) features.
    *   Performance was poor (F1 ~0.45 - 0.49) due to the loss of spatial and temporal sequence data during MFCC averaging.
4.  **Custom Deep Learning via Spectrograms:**
    *   **Audio CNN:** 4-layer CNN (16->32->64->128 channels) with Adaptive Average Pooling. Achieved F1 ~0.68.
    *   **CRNN (CNN + LSTM):** Attempted to capture temporal dynamics. Plagued by overfitting due to the parameter size versus the limited dataset size.
5.  **Transfer Learning:**
    *   **ResNet-50:** Pre-trained on ImageNet. Fine-tuned on 224x224 Mel-Spectrogram images. Utilized AdamW, StepLR, Label Smoothing (0.1), and Gradient Clipping. Reached F1 ~0.92.
    *   **Audio Spectrogram Transformer (AST):** Pre-trained on AudioSet. Leverages self-attention across the spectrogram space. Reached peak validation F1 ~0.96.
6.  **Inference and Ensembling:**
    *   Implemented Test-Time Augmentation (TTA) using shifting and amplitude scaling (4 augmentations per chunk).
    *   Final probabilities generated via weighted ensemble: 60% AST + 40% ResNet-50.

## Results

*   **Final Kaggle Leaderboard Score:** 0.954 (Macro F1)

## Key Technical Decisions

*   **Log-Mel Spectrograms:** Converting audio to images (using `power_to_db`) was crucial for leveraging powerful vision models (ResNet) and vision-derived spatial architectures (AST).
*   **Transfer Learning Dominance:** Models with pre-trained weights (ImageNet, AudioSet) vastly outperformed models trained from scratch on the 10k dataset.
*   **Handling Class Imbalance / Regularization:** Despite a balanced parent dataset, heavy augmentations and regularization policies were needed for the deep networks, including Weight Decay (0.01), Dropout (0.5), and Label Smoothing.
